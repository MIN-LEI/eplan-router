# eplan-router

EPLAN skill dispatcher: fingerprints the product (EPLAN Electric P8 vs EEC Pro),
classifies the task, names the minimal skills to read before acting, and selects the
right documentation index (2026 semantic vs 2027 keyword).

## Source / attribution

This is a personal public mirror of the **eplan-router** skill maintained by
**Canary-ECAD**, kept for learning and reference. The upstream file lives in:

- https://github.com/Canary-ECAD/eplan-scripting-skill/blob/main/eplan-router/SKILL.md

The only local change is one skill path reference (`skills/eplan-p8/eplan-scripting`
→ `eplan-scripting`) so the skill works standalone.
